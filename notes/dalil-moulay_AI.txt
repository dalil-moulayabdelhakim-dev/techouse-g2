## Session Breakdown:
1. Theoretical Lecture (lsn.mp4):
   - Introduction to Version Control Systems.
   - Core distinction: Git (Local tracking) vs. GitHub (Cloud collaboration).
   - Essential terminologies: Repositories, Commits, Branches, and Pull Requests.
   - Project blueprint: README.md, .gitignore, LICENSE.

2. Practical Workshop (pratique.mp4):
   - Environment setup: Git installation and terminal configuration.
   - Everyday commands: git clone, git add, git commit, git push, git pull.

   - Best practices: Writing clean commit messages, handling credentials securely.
